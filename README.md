# Full Stack Open

Exercises from [Full Stack Open](https://fullstackopen.com/).

## Phonebook

Live application: [https://helsinki-course-exn8.onrender.com](https://helsinki-course-exn8.onrender.com)

### Local development

```bash
# Backend
cd part3/phonebook && pnpm dev

# Frontend (separate terminal)
cd part2/phonebook && pnpm dev
```

Production build (served from backend at http://localhost:3001):

```bash
cd part3/phonebook && pnpm run build:ui && pnpm start
```
